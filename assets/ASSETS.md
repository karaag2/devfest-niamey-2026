# DevFest Niamey 2026 — Assets

Convention de nommage : `CODE_sujet_fond_format.ext`
- CODE : A = visuel héros, V = vidéo boucle (même numéro que l'image source), B = objet isolé, C = texture
- fond : paper-bg, blue-bg, red-bg, yellow-bg, charcoal-bg, paper-green-bg
- format : 16x9, 9x16, 1x1, 4x3 · `_alt` = variante alternative du même visuel
